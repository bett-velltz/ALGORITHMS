Алгоритм:

1. Посчитать префиксные хэши строки S
2. hash[i] - полиномиальный хэш длины i от начала строки 
     h[i] = s[0]*B^(i-1) + s[1]*B^(i-2) + ... + s[i-1]*B^0
3. Для каждого запроса:
    ищем максимальный бщий кусок - одинаковый префиксный хэш для максимальной длины, а потом сравниваем следующий (разный) элемент.
    Хэш подстроки s[l..r]:
    hash(l, r) = h[r+1] - h[l] * pow[r-l+1]
