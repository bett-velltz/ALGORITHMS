идейно: берем и составляем такую строку, у которой минимум 128 анаграмм и выводим про запросе часть или все

нужен набор из двух типов символов - двух букв - где сочетания равны минимум 128, то есть строку из 5 "a" и 5 "b". C(10,5)=252 - количество вариантов выбрать 5 позиций из 10 для символа а, для в - оставшиеся

наща функция:

    int get_hash(string str) {
        int result = 0;
        for (char s : str) {
            result = (result + static_cast<int>(s)) % 128;
        }
        return result;
    }
