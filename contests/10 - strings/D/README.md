Идея: алгоритм Манакера

1. Запустить алгоритм Манакера для строки.
2. Для каждой позиции считаем:
    
    d1[i] — радиус нечётного палиндрома с центром в i
    d2[i] — радиус чётного палиндрома с центром между i-1 и i

3. Для каждого центра:

нечётные палиндромы дают вклад d1[i] - 1 (вычитаем палиндром длины 1);
чётные палиндромы дают вклад d2[i].

4. Просуммировать все вклады:

    ans = Σ(d1[i] - 1) + Σ d2[i];

5. Вывести ans.
