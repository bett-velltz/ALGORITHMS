ИДЕЯ:

Пусть R — перевёрнутая строка S. Тогда A(i) — это Z-функция конкатенации:
T = S + "#" + R

## Алгоритм

1. Берём строку S и строим перевёрнутую строку R.

2. Склеиваем `T = S + "#" + R`.

3. Считаем Z-функцию от T.

4. Для каждого i от 1 до n: позиция в T, соответствующая i — это `(n+1) + (n-i)`. Z-значение в этой позиции и есть A(i), но не больше i.

5. Отдельно обрабатываем `i = n`: проверяем, является ли вся строка палиндромом (S == R), тогда A(n) = n, иначе смотрим z[n+1].
